我想要开发一个仓库定时同步系统：

源：Gitee、GitHub

目标：Gitee、Github、WebDAV、本地存储

定时：corn表达式、通用的 每天、每周、 每月等 精确到分

定时同步上游仓库最新内容，支持查看本地仓库列表（网格、列表切换展示）、仓库详情(仓库内容、上游地址等信息)、删除仓库、添加（根据上游仓库地址添加，添加时首次拉取同步一次上游仓库内容）、AI功能（可以设置AI厂商【允许设置多个，但是只有一个能生效】），利用生成长每个仓库的概要介绍

支持手动检测仓库是否和上游仓库有差异。
列表要支持搜索、筛选等常用功能。

设置功能：登录系统需要密码，登录之后可以修改密码。

时区用 Asia/Shanghai
保留最近7天的同步日志(默认7天、 可以允许在设置中调整，但是最大限制6个月)，每次同步留日志（开始、结束、上游、每个目标、错误摘要）


前后端分离:
后端写在backend目录中, 后端使用Python开发, 并使用uv工具管理环境;
数据库要支持多种数据库（SQLite / PostgreSQL / MySQL），默认sqlite

前端写在frontend目录中,使用vite、react、shadcn/ui、tailwindcss等相关技术;

并且创建makefile,使用make指令一次性启动前后端.
