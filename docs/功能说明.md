# 功能说明

本文只记录当前已经能使用的行为。需求全文见 `docs/需求规格说明.md`。

## 已可用

- 管理员密码登录、退出、修改密码。修改密码后其他会话失效。连续失败会暂时锁定登录。
- 用 HTTPS 地址添加 GitHub 或 Gitee 仓库。添加时先确认地址可访问，再拉取镜像。上游失败不会留下仓库记录。
- 每个仓库一条调度：每天、每周、每月或五段 Cron，时区为 Asia/Shanghai。可以暂停定时，仍可手动同步。
- 同一仓库不会并行同步。列表里点一个仓库的同步，不会锁住其他仓库和多选同步。定时触发时如果上次还在跑，会写一条「跳过」日志。
- 添加仓库时可以选择保存方式，允许多选，默认勾选本地。GitHub、Gitee、WebDAV 使用设置里配置的账户，位置按上游仓库自动确定，不用填写地址；账户未配置时不能勾选，问号会说明原因。至少保留一种。
- 设置里可以修改本地镜像目录，也可以打开这台电脑的文件夹窗口来选择。点保存时才会询问是否把现有镜像同步到新目录。选择同步会搬迁文件并更新路径。选择不同步时，原先只保存在本地的仓库会从列表移除，文件留在原目录；还有其他保存方式的仓库会去掉「本地」。
- 仓库列表和详情会显示每种保存方式及其位置。详情里失败的保存方式可以单独重试，只重做这一处，不重新拉取上游。编辑仓库时，地址没变的保存方式会保留上次的成功或失败结果。
- 差异比较的是本地镜像和上游的分支、标签。一致表示两边相同，落后于上游表示上游有本地没有的新提交，历史分叉表示两边都有对方没有的提交，比较失败为检测失败，还没比较过是未检测。同步成功拉取上游后记为一致；拉取失败记为检测失败。详情里也可以手动检测差异。手动立即同步会再次拉取并更新目标。保存方式和上游同平台时，优先 fork 上游，这样目标页面会显示上游链接；已经存在的同名普通仓库会先删掉再 fork。跨平台时才创建私有空仓库。之后推送分支和标签，不推送 `refs/pull` 这类隐藏引用。
- 仓库列表支持搜索、按平台、同步状态和差异结果筛选，按名称或最近同步排序，并在网格和列表之间切换。上游和保存方式分开标出：上游用下载图标，保存方式用上传或硬盘图标。
- 详情页把 AI 概要放在仓库内容上面。可以只读浏览默认分支：目录列表完整展开，按目录进入子文件夹，打开文本和 Markdown。Markdown 会按标题、表格、列表和其中的 HTML 渲染，相对路径的图片从本地镜像读取。查看文件时可以在新窗口打开上游仓库里的对应文件。二进制文件只显示大小。同时展示保存方式和位置、这条仓库的同步日志、最近 20 条提交、体积、分支数和标签数。详情页用「内容、保存方式、日志、提交」分开显示。内容页里的文件正文按实际长度展开。日志和提交在各自区域里滚动。可以一次添加多种保存方式，不用填写地址：GitHub 和 Gitee 使用设置里的账户，仓库名与上游相同；WebDAV 写到设置里的地址下，目录为 /拥有者/仓库名。添加后会立刻做一次同步。
- 仓库列表可以单条或多选后同步、删除。删除仓库会删掉本系统记录，以及每种保存方式里的对应内容：本地镜像、WebDAV 目录，还有 GitHub 或 Gitee 上的目标仓库。保存目标如果就是上游地址，则保留上游。同步进行中不能删除。
- 同步日志记录开始、结束、触发方式、上游结果和每个目标的结果。日志页看全部，仓库详情只看该仓库最近 50 条。保留天数默认 7，可改为 1 到 180，超期自动清理。
- 可以保存多个 AI 厂商，同时只能启用一个。点「添加 AI 厂商」后才出现表单，点保存才写入。已添加的可以编辑和复制；复制出来的一份默认不启用。启用中的厂商不能删除，需要先停用。添加时可以拉取 OpenAI 兼容接口的模型列表，已保存的密钥可以查看。概要只由 AI 生成，没有生成时显示「AI未生成」。详情里点生成概要时，如果没有启用的厂商，会提示先到设置里启用。生成失败不影响同步。
- 设置里可以填写 http 或 https 代理。添加仓库和添加 AI 厂商时可以选择是否使用；没有保存代理地址时不能勾选。勾选后，这个仓库的拉取、推送、WebDAV 和这个厂商的请求会走该代理。
- 顶栏和设置页可以搜索并切换 42 套 tweakcn 主题，以及浅色、深色、跟随系统。刷新后仍保持。
- `make dev` 同时启动前端和后端。

## 验证情况

- 后端 pytest 覆盖调度、地址校验、登录与会话失效、日志保留上限、AI 单厂商启用、本地 Git 仓库的添加、目录、README、提交、差异和删除。
- 前端 vitest 覆盖主题目录、颜色回退、阴影、损坏的本地存储，以及主题搜索和模式切换。
- 默认 SQLite 已跑通上述测试。
- 浏览器已走通：用 `change-me` 登录进入仓库列表；主题切换到 Vercel 并在刷新后保持；设置页可打开；添加公开仓库 `https://github.com/octocat/Hello-World` 后首次同步成功，详情页能看到目录、`README` 正文和最近提交；手动检测差异结果为「一致」；同步日志有一条「首次添加 / 成功」。

## 尚未在当前环境实测

- PostgreSQL 和 MySQL：代码按 SQLAlchemy URL 切换，但这台机器没有启动这两种数据库，所以没有做空库增删查。
- Gitee、私有仓库令牌、镜像推送到远程 Git、WebDAV 上传，以及真实 AI 厂商：需要你自己的地址和密钥后再试。公开 GitHub 的拉取和差异检测已经在浏览器里验证过。

## 使用

1. 在仓库根目录执行 `make dev`。
2. 打开 `http://127.0.0.1:5173`，用 `.env` 里的 `INITIAL_ADMIN_PASSWORD` 登录。示例文件里的默认值是 `change-me`。
3. 在设置中修改密码。平台凭证按 GitHub、Gitee、WebDAV 分开保存和测试；密钥留空不会覆盖已保存的值，也可以单独清除。GitHub、Gitee 令牌旁的问号会说明：公开仓库只保存在本地时不用令牌；私有仓库或要创建、fork、推送、删除目标时要哪些权限。Gitee 的生成新令牌页面会默认勾选全部权限，链接不能改这个默认，提交前只保留 user_info 和 projects。需要代理时先保存地址，再在仓库或 AI 厂商上勾选。AI 厂商点添加后填写，保存后可以编辑和复制，也可以获取模型列表、查看已保存的密钥。
4. 在仓库页粘贴上游 HTTPS 地址并保存。首次同步完成后出现在列表中。
