# 架构说明

仓库定时同步系统是前后端分离的单管理员工具。浏览器只通过 HTTP API 访问后端，不直接连接数据库。

## 目录

- `backend/`：Python API，使用 uv 管理依赖
- `frontend/`：Vite、React、Tailwind CSS 和按 shadcn/ui 方式落地的组件
- `data/`：运行后生成，存放 SQLite、加密密钥和 Git 镜像，不进入源码
- `docs/`：需求、架构和功能说明

## 后端

后端使用 FastAPI 和 SQLAlchemy 2。`make dev` 通过 `uvicorn app.main:create_app --factory` 启动，默认监听 `127.0.0.1:8000`。

数据层只依赖 SQLAlchemy 的 URL。默认数据库是 `data/app.db`（SQLite，开启 WAL）。把环境变量 `DATABASE_URL` 改成 `postgresql+psycopg://...` 或 `mysql+pymysql://...?charset=utf8mb4` 即可切换。表在启动时由 `create_all` 创建。已有 SQLite 库会补上 `repos.save_local` 和 `app_settings.local_mirror_dir`。

主要模块：

- `app/main.py`：组装应用、初始化管理员和设置、挂上路由
- `app/models.py`：管理员、会话、设置、AI 厂商、仓库、保存方式和目标、同步日志
- `app/storage.py`：本地镜像目录，以及切换目录时的搬迁或移除
- `app/security.py`：Argon2 密码、HttpOnly Cookie、登录失败限流
- `app/crypto.py`：用 Fernet 加密令牌和 WebDAV 密码。密钥来自 `SECRET_KEY`，否则写入 `data/secret.key`
- `app/sync_service.py`：同一仓库互斥；全局并行数来自设置，默认 2。删除仓库时先删 WebDAV 目录和 GitHub、Gitee 上的目标仓库；目标与上游是同一地址时保留上游。远程删除失败则不删本系统记录和本地镜像
- `app/git_ops.py`：`git clone --mirror`、`git remote update --prune`。推送到 GitHub 或 Gitee 时只强制更新并修剪分支和标签，不推送 `refs/pull`。与上游同平台时先 fork，跨平台时才创建私有空仓库。另有只读目录、文本和图片预览、Markdown 相对图片的原始字节、最近提交
- `app/webdav_client.py`：把默认分支工作区上传到 WebDAV，不上传 `.git`
- `app/scheduler.py`：每 5 秒检查一次，按 Asia/Shanghai 判断当前分钟是否命中调度。同一分钟只触发一次。进程刚启动的那一分钟不补跑
- `app/summary_service.py`：调用当前启用的 OpenAI 兼容接口生成概要。失败只返回提示

调度支持每天、每周、每月和五段 Cron。每月若所选日期不存在，则在该月最后一天的同一时分执行。

上游和 Git 目标只接受 `github.com` 与 `gitee.com` 的 HTTPS 地址。令牌在执行 git 时临时写入 URL，结束后改回不含令牌的地址。网络类错误最多重试 3 次。

## 前端

前端默认 `http://127.0.0.1:5173`，开发服务器把 `/api` 代理到后端，登录 Cookie 保持在同一来源。

页面：

- 登录
- 仓库列表：搜索、筛选、排序，网格和列表记在 localStorage。可以单条或多选后同步、删除
- 仓库详情：AI 概要在仓库内容上面，另有目标、目录、README、最近提交、差异检测和同步
- 日志
- 设置：密码、保留天数、并行数、本地目录（可打开系统文件夹窗口）、代理、凭证、AI 厂商、主题

界面组件放在 `frontend/src/components/ui/`，使用 Radix Dialog、class-variance-authority 和 Tailwind 语义色，对应 shadcn/ui 的用法。

## 主题

主题预设和显示模式分开。预设来自 tweakcn 提交 `a3b47b37cba97dd637de517aab52c45ec0f83456`，当前生成 42 套。来源、哈希和 Apache-2.0 许可证见 `THIRD-PARTY-NOTICES.md`。

`frontend/scripts/sync-tweakcn-themes.mjs` 从已提交的上游副本生成：

- `frontend/src/lib/theme-catalog.generated.ts`
- `frontend/public/theme-init.js`
- `frontend/public/licenses/APACHE-2.0.txt`

`npm run theme:check` 离线核对哈希和产物，不访问网络。

`index.html` 在绘制前同步执行 `theme-init.js`。React 挂载前，`bootstrapTheme` 再用同一套校验规则写入 CSS 变量。顶栏和设置页都使用 `ThemePresetSelector`，状态只在 `ThemeProvider` 中。偏好保存在 localStorage 键 `repository-sync.theme`，不写数据库。颜色缺失只回退到默认主题的同一模式。`shadow-opacity` 会参与 `color-mix` 阴影。

## 启动

```bash
make dev
```

首次会从 `.env.example` 复制 `.env`。默认管理员密码是 `change-me`，登录后应立即修改。忘记密码时设置 `ADMIN_PASSWORD_RESET=1` 并保留 `INITIAL_ADMIN_PASSWORD`，重启后再把重置开关改回 `0`。
